## ⚡ OPTION 1: Master Prompt (Sekali Tempel / 1-Click Generate)
> **Cara Pakai di Canva:**
> 1. Buka [Canva.com](https://www.canva.com) &rarr; pilih menu **Presentations (16:9)**.
> 2. Klik fitur **Magic Design** (ikon bintang ajaib) atau ketik di kolom pencarian template Canva.
> 3. Salin (copy) prompt di bawah ini lalu tempel:

```text
Buatkan presentasi profesional 10 slide tentang "Rancang Bangun Prototipe Chatbot Penjualan WhatsApp Dimsum Mentai Oishi Berbasis Flask & SQLite".

Tema Desain:
- Gaya: Modern, Tech-Culinary, Sleek, Professional.
- Palet Warna: Dark Navy (#111827), Warm Mentai Orange (#FF6B35), WhatsApp Green (#25D366), Gold Accent (#FBBF24), dan Pure White text.
- Elemen Visual: Mockup smartphone WhatsApp chat, diagram arsitektur alur data, kartu menu dimsum lezat, dan mockup dashboard admin.

Struktur 10 Slide:
Slide 1: Judul Proyek - Rancang Bangun Chatbot Penjualan WhatsApp "Dimsum Mentai Oishi" (Otomasi Transaksi Pemesanan Makanan Real-Time).
Slide 2: Masalah UMKM - Admin kewalahan balas chat di jam sibuk, respon lambat (>5 menit) bikin order batal, sering salah catat porsi/alamat manual.
Slide 3: Solusi 3-in-1 - WhatsApp Bot Nyata (scan QR 24/7), Web Chat Simulator (demo kelas), dan Dashboard Admin Real-Time.
Slide 4: Menu Dimsum - Mentai Original (Rp25k), Mentai Spicy (Rp27k), Cheese Melt (Rp28k), Platter Party (Rp95k).
Slide 5: Arsitektur Sistem - Alur Gateway Node.js/whatsapp-web.js (Chromium headless) -> Flask Webhook Python -> SQLite Database.
Slide 6: Alur Percakapan Bot - Finite State Machine (Halo -> Pilih Menu -> Input Porsi -> Input Nama -> Input Alamat -> Konfirmasi YA -> Nota Final).
Slide 7: Fitur Unggulan - Respon instan <3 detik, anti-crash singleton lock cleaner, self-service cek pesanan, zero-cost API open-source.
Slide 8: Tech Stack - Python Flask, Node.js whatsapp-web.js, Puppeteer, SQLite3, Bootstrap 5.
Slide 9: Roadmap Masa Depan - Integrasi Payment Gateway QRIS otomatis, integrasi kurir instan Gosend/Grab, dan AI NLP Smart CRM.
Slide 10: Kesimpulan & Q&A - Efisiensi pangkas waktu 85%, akurasi 100%, siap live demo. Terima Kasih & Sesi Tanya Jawab.
```

- **Headline:** Logika Percakapan Terstruktur & Anti-Salah
- **Poin Utama:**

  - `INPUT_QTY`: Menentukan jumlah porsi & pengecekan stok.
  - `INPUT_NAME & ADDRESS`: Pendataan nama pembeli & alamat kurir.
  - `CONFIRMING`: Draf nota lengkap & konfirmasi 'YA'.

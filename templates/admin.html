Panduan Integrasi WhatsApp (WPPConnect + Ngrok)
Langkah 1: Menjalankan Server Flask
python app.py

Aplikasi berjalan pada port 5000.

Langkah 2: Menghubungkan Ngrok ke Flask
ngrok http 5000

Salin URL HTTPS ngrok yang dihasilkan, contoh: https://abc123xyz.ngrok-free.app

Langkah 3: Atur Webhook di WPPConnect Server

Daftarkan endpoint webhook Flask ke WPPConnect Server:

POST {WPP_SERVER}/api/dimsum-session/webhook
Payload: {"url": "https://abc123xyz.ngrok-free.app/webhook"}
Mode Presentasi Offline: Jika WPPConnect server belum terpasang, Anda tetap dapat melakukan demo presentasi interaktif 100% menggunakan Chatbot Simulator.

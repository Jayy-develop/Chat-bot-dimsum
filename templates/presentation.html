01. LATAR BELAKANG & MASALAH

Tantangan Pemesanan Manual UMKM Kuliner

Tantangan Operasional
Admin Kewalahan
  • Banjir chat di jam sibuk makan siang dan malam membuat admin lambat membalas.
  • Customer sering membatalkan pesanan (churn) jika menunggu balasan lebih dari 5 menit.
  • Keterbatasan jam kerja manusia yang tidak bisa aktif 24 jam nonstop.
Akurasi Transaksi
Human Error Tinggi
  • Sering terjadi salah catat varian dimsum, jumlah porsi, atau salah hitung total biaya.
  • Alamat pengantaran sering terlewat atau tidak tercatat lengkap oleh kurir.
  • Rekap keuangan manual di kertas/spreadsheet memakan waktu di akhir hari.
Peluang Solusi
Kenapa WhatsApp?
  • Penetrasi WhatsApp di Indonesia lebih dari 88%, dipakai oleh semua kalangan.
  • Customer enggan mengunduh aplikasi toko baru karena memori HP terbatas.
  • Pengalaman belanja terasa lebih personal, cepat, dan mudah diakses.

  • Ubah status order sekali klik: Menunggu → Diproses → Selesai.
  • Panel uji coba kirim pesan WhatsApp keluar langsung dari web.

04. ARSITEKTUR TEKNOLOGI

Aliran Data & Integrasi Gateway

1. WhatsApp Gateway
Node.js + Chromium
  • Menghubungkan nomor HP bot menggunakan whatsapp-web.js.
  • Menangkap pesan masuk dari customer dan mengekstrak nomor HP serta teks.
  • Meneruskan payload via HTTP POST ke endpoint /webhook Flask.
2. Bot Engine
Python Flask Core
  • Memproses percakapan menggunakan algoritma Finite State Machine (FSM).
  • Melacak status order tiap nomor: IDLE, PILIH, JUMLAH, ALAMAT, KONFIRMASI.
  • Menyusun balasan ramah otomatis dan mengembalikan teks respons ke gateway.
3. Database & Admin
SQLite 3 Relational
  • Menyimpan tabel: customers, orders, dan products.
  • Stok produk otomatis terpotong saat pesanan disetujui (checkout).
  • Dashboard Admin menampilkan data pesanan dan pembaruan status realtime.
05. LOGIKA PERCAKAPAN

State Machine Percakapan Pemesanan

Fase 1: Mulai & Menu
1. Sapaan & Pilihan
  • Customer ketik Halo / Mulai → Bot menampilkan 3 opsi menu.
  • Ketik 1. Lihat Produk → Katalog menu dan harga ditampilkan.
  • Ketik 2. Pesan → Bot meminta memilih nomor varian menu.
Fase 2: Detail Order
2. Porsi & Alamat
  • Bot menanyakan jumlah porsi → Validasi angka dan cek stok.
  • Bot meminta nama pemesan untuk nota transaksi.
  • Bot meminta alamat lengkap pengantaran untuk kurir.
Fase 3: Checkout
3. Konfirmasi & Nota
  • Bot menampilkan ringkasan nota lengkap dengan total harga.
  • Customer ketik YA → Order tersimpan resmi di database.
  • Kapan saja customer bisa ketik Batal untuk me-reset sesi belanja.
06. KEUNGGULAN SISTEM

Fitur Unggulan Dimsum Mentai Bot

Resilient Gateway & Anti-Crash

Pembersihan Chromium SingletonLock otomatis mencegah error tabrakan browser, serta dukungan auto-reconnect saat jaringan terputus.

Respon Instan di Bawah 3 Detik

Proses parsing pesan di memori lokal menghasilkan respons seketika tanpa jeda antrean server eksternal berbayar.

Self-Service Cek Status Pesanan

Customer dapat mengecek status pesanan mereka sendiri kapan saja lewat opsi "3. Cek Pesanan" tanpa perlu bertanya ke admin.

Nol Biaya Langganan API (Zero Cost)

Menggunakan WhatsApp Web library open-source tanpa perlu mendaftar WhatsApp Cloud API berbayar bulanan.

07. SPESIFIKASI TEKNIS

Daftar Teknologi yang Diimplementasikan

Backend
Python & Flask
  • Python 3.10+: Bahasa logika percakapan utama.
  • Flask 3.0: Routing REST API, webhook, dan Jinja2 template rendering.
  • SQLite 3: Basis data relasional ringan tanpa konfigurasi server terpisah.
Gateway
Node.js Ecosystem
  • whatsapp-web.js: Klien otomasi WhatsApp Web.
  • Puppeteer Core: Peramban Chromium headless.
  • qrcode-terminal & qrcode: Visualisasi kode QR terminal dan web.
Frontend UI
Modern Web Design
  • Bootstrap 5.3: Grid sistem responsif dan kartu modern.
  • Bootstrap Icons: Ikon visual intuitif.
  • Vanilla JS (Fetch API): Komunikasi asynchronous tanpa reload.
